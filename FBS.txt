ABSTRACT
Supply chain management plays a critical role in the global economy, enabling the seamless movement of goods from manufacturers to consumers through a network of interconnected entities. Among the most essential components of this system is shipment tracking, which ensures visibility, accountability, and timely delivery of goods. However, traditional shipment tracking systems rely on centralized architectures where all data is managed by a single authority, making them vulnerable to data manipulation, lack of transparency, and trust issues among stakeholders.
In response to these challenges, this project presents the Blockchain-Based Shipment Tracking System, a comprehensive and secure decentralized platform designed to automate and manage the entire lifecycle of shipment tracking. The system integrates multiple advanced components, each addressing a critical aspect of supply chain transparency and data integrity. The first component is a decentralized ledger mechanism implemented through smart contracts on a blockchain network, which continuously records shipment events in an immutable and tamper-proof manner. The second component focuses on role-based access, enabling stakeholders such as manufacturers, transporters, warehouse managers, and customers to interact with the system based on their designated permissions.
The third component introduces a centralized dashboard and API layer that allows real-time querying of shipment status, location updates, and transaction history across the supply chain. This is complemented by a smart contract-based automation model that triggers status updates, validates transactions, and enforces business rules without requiring manual intervention. Additionally, the system incorporates a comprehensive economic transparency model that logs costs, transit times, and delivery performance indicators, ensuring realistic representation of real-world supply chain operations.
By combining decentralized data storage, smart contract automation, role-based access control, and real-time tracking capabilities, the Blockchain-Based Shipment Tracking System establishes a scalable and modular platform for secure supply chain management. The integration of these components results in a cohesive system capable of improving operational efficiency, reducing fraud risks, and enabling proactive infrastructure governance in modern logistics environments.

Chapter 1: Introduction
Supply chain management represents a critical component of modern economies, directly influencing transportation efficiency, business productivity, and consumer trust. Shipment tracking is an essential function within this ecosystem, ensuring that goods are monitored from origin to destination in a transparent and reliable manner. However, the lack of continuous and trustworthy monitoring remains a persistent challenge in global supply chains. Traditional tracking systems depend on centralized databases managed by a single authority, which creates vulnerabilities related to data tampering, fraud, and lack of transparency among stakeholders.
Because of this centralized nature, early detection of discrepancies, unauthorized modifications, and delayed updates remain major challenges in logistics management. Traditional systems frequently fail to provide real-time visibility, and inconsistencies often arise due to separate record-keeping by different participants such as suppliers, transporters, and warehouses. In recent years, blockchain technology and smart contract systems have emerged as powerful tools capable of automating supply chain monitoring and ensuring data integrity. For logistics systems, these technologies can record events immutably, enforce business rules automatically, and improve resource coordination beyond manual capabilities. This project aims to create a unified, intelligent platform for automated shipment tracking, secure data management, and decentralized transparency leveraging blockchain technology and web-based interfaces.
1.1 Overview of Blockchain-Based Shipment Tracking System
The Blockchain-Based Shipment Tracking System introduced in this work is designed as an integrated decentralized framework that combines three complementary components: shipment event logging via blockchain, intelligent role-based access control, and real-time dashboard management. Shipment properties such as shipment ID, origin, destination, current status, timestamp, and stakeholder identity are recorded using immutable smart contracts deployed on a blockchain network, enabling accurate identification and verification of shipment data.
Interaction within the system is handled through a RESTful API layer, which enables various stakeholders—manufacturers, transporters, warehouses, and customers—to query and update shipment status in a structured and validated manner. The system models the supply chain as a network of interconnected nodes representing participants, ensuring structured data flow and optimal transaction sequencing. Participants dynamically update records at each checkpoint, allowing full traceability of the shipment lifecycle within the system.
The system also incorporates a centralized management dashboard that prioritizes alerts based on delay severity and delivery exceptions, ensuring optimal resource utilization and timely intervention. A Shipment Registry maintains a real-time database of all tracked shipments, including their attributes and current state. The system processes this information to generate prioritized alerts and delivery schedules, balancing urgency and operational constraints to maximize supply chain efficiency.
Shipment updates are recorded automatically on the blockchain at each checkpoint, completing the lifecycle from shipment creation to delivery confirmation within a unified framework. The system further integrates a cost and performance estimation model, where transit metrics are logged based on real-world data, enhancing the realism and applicability of the platform. Additionally, the system provides real-time feedback through a dashboard interface that displays shipment counts, transaction logs, and performance indicators.
Overall, the Blockchain-Based Shipment Tracking System represents a scalable and modular smart logistics solution that transforms traditional reactive and centralized tracking into a proactive, decentralized, and automated process—improving supply chain transparency, reducing operational delays, and enabling efficient and trustworthy shipment management.

1.2 Problem Statement
Supply chain infrastructure is constantly subjected to operational complexity due to the involvement of multiple stakeholders, varying transport conditions, and the need for accurate real-time data. Traditional shipment tracking systems are designed using centralized databases and isolated data management approaches, which limit their efficiency in real-world supply chain environments. These systems often lack transparency among stakeholders, making it difficult to verify shipment status accurately.
Since data is controlled by a single entity, there is a high risk of data manipulation and fraud. Additionally, different participants such as suppliers, transporters, and warehouses maintain separate records, leading to inconsistencies and trust issues. Delays in updating shipment information further reduce real-time visibility and system reliability. Traditional methods also lack integration, scalability, and real-time decision-making capabilities.
Another major challenge lies in the dynamic nature of global supply chains. Shipment conditions can change rapidly depending on carrier performance, customs clearance, weather disruptions, and route changes. Some shipments face delays due to unforeseen circumstances, while others arrive ahead of schedule, making it difficult to maintain accurate delivery commitments. Additionally, managing thousands of shipments across multiple geographies requires efficient coordination between tracking systems, data storage, and verification units.
To address these challenges, there is a need for an integrated system capable of automating shipment tracking, ensuring data integrity through decentralization, and managing resources efficiently using blockchain technology.

Chapter 2: Literature Survey
Research on shipment tracking and supply chain management has evolved from traditional manual inspection methods to advanced blockchain-based and simulation-driven approaches. Early studies primarily focused on centralized database systems and enterprise resource planning (ERP) tools for managing logistics operations. With the advancement of IoT and sensing technologies, methods such as RFID-based tracking, GPS-enabled monitoring, and barcode scanning began to improve detection accuracy and real-time visibility.
Parallel developments in distributed ledger technologies led to the adoption of blockchain and smart contract models that enabled decentralized, transparent, and tamper-proof recording of supply chain events. Recent literature highlights the importance of integrating multiple components—decentralized data storage, intelligent access control, and centralized management frameworks—to create more efficient and scalable shipment tracking solutions.
2.1 Traditional Shipment Tracking and Detection Methods
Traditional shipment tracking approaches are primarily based on long-established manual processes and centralized database architectures that provide basic insights into shipment status. These methods continue to be widely used by logistics companies, forming the foundation for package monitoring, status reporting, and delivery confirmation. The tracking process typically begins with physical entry of shipment data by field workers, where details such as origin, destination, and carrier information are recorded through direct manual input.
These conventional approaches rely heavily on human effort and subjective judgment, which often leads to inconsistencies in data entry and status updates. Factors such as network connectivity, system downtime, and manual input errors influence the accuracy of tracking. Additionally, traditional systems lack real-time monitoring capabilities, causing delays between shipment events and visible status updates. As a result, minor discrepancies may evolve into significant delivery failures before being detected and addressed.
Some modern extensions of traditional methods include RFID-based tracking, GPS monitoring, and barcode scanning systems. These technologies attempt to improve tracking efficiency; however, they often operate as standalone solutions without proper integration into a decentralized management framework. Furthermore, they may struggle with scalability in large multi-stakeholder environments and fail to provide efficient coordination between detection, decision-making, and verification processes.

2.2 Blockchain and Smart City Logistics Systems
Blockchain technologies have emerged as a modern approach to address the limitations of traditional shipment tracking systems by incorporating decentralization, data-driven decision-making, and scalable infrastructure management. In the context of shipment tracking, these systems leverage a combination of distributed ledgers, smart contracts, and cryptographic mechanisms to continuously monitor and manage supply chain operations. Unlike conventional methods, blockchain-enabled systems provide tamper-proof records, faster verification, and trustless interaction between stakeholders.
One of the key advancements in this domain is the use of smart contracts deployed on platforms such as Ethereum or Hyperledger Fabric, which allow automatic enforcement of business rules and real-time status updates. These environments support the implementation of role-based access control systems that can simulate real-world operations, including shipment verification and multi-party approval workflows. Blockchain-based tracking enables accurate identification of shipment status through cryptographic validation and consensus mechanisms.
Another important aspect of modern systems is intelligent access management, where stakeholder-specific permissions ensure that only authorized participants can update or view sensitive shipment data. These mechanisms allow logistics networks to efficiently handle complex multi-party environments, dynamically adapt to changing roles, and optimize data flow for both detection and resolution tasks. Additionally, centralized dashboard systems play a crucial role by maintaining a registry of shipments, prioritizing alerts based on severity, and managing delivery performance constraints.
Blockchain-based smart systems also incorporate economic modeling to estimate delivery costs and performance metrics using real-world data, improving decision-making in resource allocation. The integration of tracking, access control, and management components into a unified framework enhances system reliability and scalability. This approach demonstrates how modern distributed technologies can transform traditional logistics into an intelligent, automated, and efficient process.

4.4 System Components and Algorithms
Tracking Component
The tracking system uses smart contract-based event emission to record each shipment update on the blockchain. Events such as ShipmentCreated, StatusUpdated, and DeliveryConfirmed are emitted automatically upon valid stakeholder interactions, ensuring continuous and auditable monitoring of supply chain activity.
Access Control Algorithm (Role-Based)
The system implements role-based access control (RBAC) using Solidity modifiers. Each function in the smart contract is protected by role checks, ensuring that only authorized addresses (e.g., Manufacturer, Transporter, Warehouse Manager) can invoke specific state-changing operations.
Alert Management System
The Alert Manager maintains a prioritized queue of shipment exceptions based on delay severity and delivery thresholds. It ensures optimal scheduling of interventions and prevents unnecessary resource allocation by automatically escalating critical cases.
Economic Model
The cost of delivery is calculated using the formula: Cost = Distance × Weight × Unit Rate. This ensures realistic representation of logistics budgeting and performance tracking within the system.

5.1 Smart Contract Development
The implementation of the smart contract module focuses on recording shipment events in a secure and immutable manner on the blockchain. The contract defines a Shipment struct that stores all relevant attributes including shipment ID, origin, destination, current status, stakeholder addresses, and timestamps. Each shipment is stored in a mapping keyed by its unique ID, enabling efficient retrieval and status updates.
The contract exposes several key functions: createShipment(), updateStatus(), and confirmDelivery(). Each function is protected by role-based modifiers such as onlyManufacturer, onlyTransporter, and onlyCustomer, ensuring that only authorized accounts can invoke specific operations. Upon successful execution, events such as ShipmentCreated and StatusUpdated are emitted, providing an auditable log of all supply chain activities.
To optimize performance, the contract uses mappings and events instead of arrays to minimize gas costs and reduce unnecessary on-chain storage. The deployment is managed using Truffle or Hardhat frameworks, and the compiled ABI is used by the backend API to interact with the contract. This module forms the core of the system by providing continuous and automated recording of shipment lifecycle events.

5.2 Backend API and Blockchain Integration
The backend API layer is implemented using Node.js with Express.js to enable efficient RESTful communication between the React.js frontend and the deployed blockchain smart contracts. The API uses Web3.js or Ethers.js to interact with the blockchain network, sign transactions on behalf of authorized stakeholders, and retrieve on-chain data such as shipment status and event logs.
The API exposes endpoints such as POST /shipment/create, PUT /shipment/update/:id, and GET /shipment/:id for core shipment management operations. Each endpoint validates incoming requests, authenticates stakeholder roles using signed JWT tokens mapped to blockchain wallet addresses, and invokes the corresponding smart contract functions. Dynamic re-querying is also implemented, allowing the dashboard to refresh shipment states whenever new transactions are confirmed on the blockchain.

5.3 Dashboard and Real-Time Tracking
The dashboard and real-time tracking module is implemented as a centralized control interface responsible for visualizing shipment status, transaction logs, and performance alerts across the supply chain. The Dashboard Manager maintains a live view of all active shipments and surfaces prioritized exceptions based on delay severity levels and delivery thresholds. Once a shipment is flagged, the system assigns the responsible stakeholder and provides navigation instructions through the API to reach and resolve the exception. Upon resolution, the shipment state is updated to the next stage in the blockchain registry, and the dashboard reflects this change in real time.
A key component of this module is the economic performance model, which logs delivery costs and transit times based on real-world parameters. The cost is determined using the formula: Cost = Distance × Weight × Unit Rate. The unit rate is derived from real-world logistics data, ensuring that the system reflects practical budgeting scenarios. The system continuously tracks total expenditure and flags shipments that exceed the allocated delivery budget.

The application state is managed using React Context, ensuring consistent data flow across all components. Real-time updates are achieved by subscribing to blockchain event listeners that trigger UI re-renders whenever new transactions are confirmed on the network.
